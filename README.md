# 🎮 Umar Battle Royale

A fast-paced 3D battle royale survival shooter that runs directly in your browser — on mobile and desktop. Drop in, loot up, survive the storm, and be the last one standing!

## 🔥 Features
- 🪂 Parachute drop — choose your landing spot
- 🗺️ Large island map with buildings, forests, and a lake
- 🤖 1 vs 30 AI bots (Easy / Medium / Hard)
- 🌪️ Shrinking safe zone with 5 phases
- 🔫 Pistol, SMG, Assault Rifle, Shotgun, Sniper
- 🛡️ Helmets, armor, medkits, grenades & rarity-based loot
- 📱 Mobile touch controls + desktop keyboard/mouse
- 🧭 Minimap, kill feed, damage numbers, hit markers
- 🎨 Character customization
- 🔊 Procedural sound effects (Web Audio API)
- 🏆 "BOOYAH!" victory screen

## 🕹️ Controls
| Action | Desktop | Mobile |
|---|---|---|
| Move | WASD | Left joystick |
| Aim | Mouse | Right-side drag |
| Shoot | Left click | Fire button |
| Reload | R | Reload button |
| Jump | Space | Jump button |
| Crouch | C | Crouch button |
| Pickup | E | Pickup button |

## 🚀 How to Run
1. Clone the repo:
   `git clone https://github.com/your-username/umar-battle-royale.git`
2. Open `index.html` in your browser, or run a local server:
   `npx serve`
3. Play! 🎯
